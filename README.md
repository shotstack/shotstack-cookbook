# Shotstack Cookbook

Example applications and companion code for Shotstack guides and tutorials.

Clone this repo, or head into the folder for the example you want.

| Example | What it does |
| --- | --- |
| [examples/instagram-ai-video](examples/instagram-ai-video) | Generates a script, voiceover and background image with AI, renders a 1080x1920 video, and publishes it as an Instagram Reel. Companion code for [How to automate Instagram posts with AI video](https://shotstack.io/learn/automate-instagram-posts-with-ai-video/). |
| [examples/rapidreels](examples/rapidreels) | RapidReels — create faceless short-form videos using generative AI. [View demo](https://shotstack.io/demos/social-media-video-maker/). |
| [examples/reelestate](examples/reelestate) | ReelEstate — turn static real estate images into fully edited video slideshows. [View demo](https://shotstack.io/demos/real-estate-video-listing-maker/). |

Each example has its own README with the API keys and setup steps it needs.
